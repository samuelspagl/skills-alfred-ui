# Alfred UI

[Official source](https://www.alfredapp.com/help/alfredui/) · Checked 2026-11-19 · [Index](../../INDEX.md)

AlfredUI builds native macOS interfaces from JSON. Use the workflow object to run a package within Alfred or launch it externally. The technical reference is split across the pages indexed here; this package is an independently structured factual reference, not a verbatim manual.
