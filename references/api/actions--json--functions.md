# functions Action

[Official source](https://www.alfredapp.com/help/alfredui/actions/json/functions/) · Checked 2026-11-19 · [Index](../../INDEX.md)

Ids maps component ids to a function string or an array of function strings. Only use functions published for that target type. Unlike direct action type=function, this command can be returned by scripts or combined with earlier UI mutations. A global guarantee about order among separate ids is not provided.
