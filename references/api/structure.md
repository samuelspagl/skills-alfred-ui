# .alfredui Folder Structure

[Official source](https://www.alfredapp.com/help/alfredui/structure/) · Checked 2026-11-19 · [Index](../../INDEX.md)

A package is a directory ending in `.alfredui` containing `ui.json`. Script, component and layout references resolve from the package root, regardless of which nested file contains the reference. Additional folders are an authoring choice. The log path has a separately documented relative-path rule.
