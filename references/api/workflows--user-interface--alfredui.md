# Alfred UI

[Official source](https://www.alfredapp.com/help/workflows/user-interface/alfredui/) · Checked 2026-11-19 · [Index](../../INDEX.md)

Set the workflow object's Alfred UI file to the package location; relative paths are preferred. Choose internal or external launch. Connect a Keyword Input or Hotkey Trigger. Stacking makes Escape return to the previous view; Command-Escape forces Alfred to hide. Workflow input variables require explicit variablesconfig import; finish returns output to downstream objects.
