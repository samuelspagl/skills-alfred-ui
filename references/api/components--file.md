# file Pseudo-component

[Official source](https://www.alfredapp.com/help/alfredui/components/file/) · Checked 2026-11-19 · [Index](../../INDEX.md)

Use `{"type":"file","src":"components/card.json"}` to load component JSON while specifying placement constraints in the parent. This differs from `{file:path}`, which inserts file content during preprocessing. The page has no formal property blocks; src and type are evidenced by its example. Shared Properties explicitly warns that an id inside the referenced file can replace the wrapper id. No src-required marker is published for this pseudo-component.
