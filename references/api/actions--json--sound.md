# sound Action

[Official source](https://www.alfredapp.com/help/alfredui/actions/json/sound/) · Checked 2026-11-19 · [Index](../../INDEX.md)

Src identifies a relative/absolute sound file or a system sound by name. System sounds reside in /System/Library/Sounds and can omit the extension. Playback volume, completion callbacks and supported file formats are not listed.
