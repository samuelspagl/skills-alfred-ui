# Alfred UI Components

[Official source](https://www.alfredapp.com/help/alfredui/components/) · Checked 2026-11-19 · [Index](../../INDEX.md)

Native types documented in the component index: view, label, button, checkbox, picker, textfield, passwordfield, textarea, markdownarea, progress, imageview, dataview and webkitview. `template` is a pseudo-component linked to Templates. The separately documented `file` pseudo-component is also included here. Combine each component's local properties with Shared Properties and the parent's layout constraints. There is no promise that every general event trigger applies to every component.
