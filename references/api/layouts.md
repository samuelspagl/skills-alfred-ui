# Layouts

[Official source](https://www.alfredapp.com/help/alfredui/layouts/) · Checked 2026-11-19 · [Index](../../INDEX.md)

Layout properties live on the containing view; constraints live on each child. Desired sizes are calculated from children up to the root, then each layout distributes available space. Nested border and inline views are useful building blocks. Layout sizing is not CSS: stack means overlay, not a vertical list. Window size may be explicit or content-derived.
