# Web Browser Alfred UI Tutorial

[Official source](https://www.alfredapp.com/help/alfredui/tutorials/web-browser/) · Checked 2026-11-19 · [Index](../../INDEX.md)

Official integration walkthrough for browser controls. Use webkitview src for navigation, its changed event to observe URL changes, and back/forward/reload functions. The local browser example demonstrates these controls without assuming a JavaScript bridge. The tutorial explicitly uses args[0] for the first launch argument.
